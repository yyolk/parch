# parch docs

Look-later **GitHub Pages** layer — not a README replacement.

parch generates fixed e-ink PDF pages. This MkDocs spike is a place for:

- a [config cookbook](cookbook.md) (recipes + a downloadable TOML)
- an eventual JS bridge into the [specimen catalog](https://yyolk.github.io/parch/) (today the Pages root)

A checkout-less install (`uv tool install parch` / `pip install parch`) has no `examples/`. See [pip users](pip-users.md).
