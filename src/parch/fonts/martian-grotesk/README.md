# Martian Grotesk (specimen)

Vendored TTF subset for the greenfield SANS face:

- `MartianGrotesk-Regular.ttf`
- `MartianGrotesk-Bold.ttf`

Upstream: https://github.com/evilmartians/grotesk (`52964df` on `main`)  
This family is sans-only — `Fpdf2Plotter` keeps Liberation Serif for `face="serif"`.
