# Fonts

Plotter faces (`Fpdf2Plotter`):

- **sans** — Urbanist Regular + Bold (static TTF instances from the variable family)
- **serif** — Liberation Serif Regular + Bold

Urbanist is a geometric sans with no official serif companion. This specimen keeps
Liberation Serif for `face="serif"` (cover year, section titles) so yolk can judge
Urbanist as the workhorse sans against the existing serif pairing.

## Urbanist

Vendored TTF subset:

- `Urbanist-Regular.ttf` / `Urbanist-Bold.ttf`

Upstream: https://github.com/coreyhu/Urbanist (`fonts/ttf/` static instances)
