# Planner faces (exploratory)

## Sans — Martian Grotesk Regular + Bold

UI copy (`face="sans"`). Static TTFs only — no variable-font axes at draw time.

Vendored under `martian-grotesk/`:

- `MartianGrotesk-Regular.ttf` / `MartianGrotesk-Bold.ttf` (normal width)
- `OFL.txt` / `AUTHORS.txt`

Upstream: https://github.com/evilmartians/grotesk

Martian Grotesk is a sans family (no serif companion).

## Serif — Liberation Serif Regular + Bold

Display headers (`face="serif"`): cover year, “Year Book”, section titles.

- `LiberationSerif-Regular.ttf` / `LiberationSerif-Bold.ttf`

Upstream: https://github.com/liberationfonts/liberation-fonts/releases/tag/2.1.5

SIL Open Font License 1.1 — see `LICENSE` and `AUTHORS`.
Reserved Font Name: Liberation.
