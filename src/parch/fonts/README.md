# Jost 3.7

Vendored static TTF subset (fpdf2 cannot load the variable font):

- `Jost-400-Book.ttf` — `face="sans"` regular (text / UI)
- `Jost-700-Bold.ttf` — `face="sans"` + `bold=True` (emphasis)
- `Jost-500-Medium.ttf` — `face="serif"` titles (page titles, cover brow)
- `Jost-800-Heavy.ttf` — cover year only (`weight="heavy"`)
